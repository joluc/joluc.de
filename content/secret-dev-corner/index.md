## A Little Challenge

If you're into observability and monitoring (since you're here), try this:

Think about the last production incident you dealt with. Now ask yourself:
1. How long did it take to get the first alert?
2. How long to understand what was actually broken?
3. How long to find the root cause?

The gap between #1 and #3 is where good observability lives. That's what I'm passionate about shrinking.
